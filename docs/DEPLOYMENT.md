# 앱을 올리는 방법

이 문서는 **오늘의 말랑부적**을 토스에 올리는 순서를 적습니다.

## 1. 올리기 전에 준비할 것

### 1.1 토스 파트너 콘솔

- 주소: [https://partners-apps-in-toss.toss.im](https://partners-apps-in-toss.toss.im)
- 앱 ID: `today-lucky-charm`
- 앱 이름: 오늘의 말랑부적

### 1.2 꼭 받아 두어야 하는 것

| 무엇 | 설명 | 어디서 |
|------|------|--------|
| 앱 아이콘 주소 | 96×96px | 파트너 콘솔 → 앱 설정 |
| 다시 뽑기 광고 ID | `ait.v2.live.*` 모양 | 파트너 콘솔 → 광고 |
| 배너 광고 ID | `ait.v2.live.*` 모양 | 파트너 콘솔 → 광고 |

---

## 2. 내 컴퓨터에서 준비하기

```bash
# 1. 패키지 설치
npm install

# 2. 환경 변수 파일 만들기 (Windows)
copy .env.example .env.local
```

`.env.local`에는 광고 ID만 넣으면 됩니다.
`VITE_AD_ENV`는 이제 쓰지 않습니다.

---

## 3. 완성본 만들기

### 3.1 웹으로 미리 보기

```bash
npm run build
npm run preview  # http://localhost:4173
```

`npm run build`를 실행하면 `vite build` 다음에 `ait build`도 자동으로 실행되어,
`dist/` 폴더와 `today-lucky-charm.ait` 파일이 한 번에 만들어집니다.

### 3.2 토스에 올릴 파일만 다시 만들기

이미 `dist/`가 있고 `.ait` 파일만 다시 묶고 싶을 때 씁니다.

```bash
npm run build:ait
# today-lucky-charm.ait 파일이 생깁니다.
```

### 3.3 파일이 잘 나왔는지 보기

`_ait_inspect/` 폴더가 생기면, 그 안의 `index.html`을 브라우저로 열어 보세요.

## 4. 올리기 전에 확인할 목록

### 4.1 코드

- [ ] 토스 파트너 콘솔에 진짜 앱 아이콘을 등록했다 (SDK 3.x부터 `brand.icon` 설정이 사라지고, 콘솔에서 등록합니다)
- [ ] 광고 ID가 맞다 (`VITE_REWARD_AD_ID`, `VITE_BANNER_AD_ID` 또는 [src/lib/config.ts](../src/lib/config.ts) 기본값)
- [ ] `npm run typecheck`에 오류가 없다

### 4.2 지켜야 하는 약속

- [ ] 운세나 점이 진짜라는 말이 없다
- [ ] 돈을 준다는 말이 없다
- [ ] 광고 다시 뽑기는 하루에 한 번만 된다
- [ ] 이름이나 전화번호를 모으지 않는다 (브라우저 저장만 한다)
- [ ] 앱인토스 SDK가 3.1 이상이다 (지금은 3.4.0)
- [ ] 콘솔의 Origin 허용 목록에 아래 두 주소를 등록했다 (SDK 3.x부터 CORS 규칙이 바뀌었습니다)
  - `https://today-lucky-charm.web.tossmini.com` (실제 서비스)
  - `https://today-lucky-charm.private-web.tossmini.com` (콘솔 QR 테스트)

### 4.3 화면

- [ ] 가로 360px ~ 430px에서 깨지지 않는다
- [ ] 아래쪽 탭이 화면에서 떠 있는 알약 모양이다 (긴 막대가 아니다)
- [ ] 오늘 / 기록 / 도감 탭이 잘 움직인다
- [ ] 안드로이드 뒤로 가기가 이상하지 않다
- [ ] 어두운 모드로 바뀌지 않는다 (밝은 화면만 쓴다)

## 5. 파트너 콘솔에 올리기

1. 토스 파트너 콘솔에 로그인합니다.
2. `today-lucky-charm` 앱을 고릅니다.
3. **새 버전 등록**에서 `today-lucky-charm.ait`를 올립니다.
4. 화면 사진을 최소 2장 붙입니다.
5. 무엇이 바뀌었는지 짧게 씁니다.
6. **심사 신청**을 누릅니다.

## 7. 갑자기 문제가 생기면

### 광고가 안 나올 때

`showRewardAd()`가 실패하면 `false`를 돌려줍니다.
다시 뽑기는 되지 않습니다. 첫 부적은 그대로 둘 수 있습니다.

### 브라우저 저장이 깨졌을 때

브라우저 데이터를 지우면 기록도 같이 사라집니다.
지금은 그게 전부입니다. 나중에 다른 저장소로 옮길 수 있습니다.
